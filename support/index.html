Before you write

A quick check on these four points solves most SourceTrac questions.

  • The survey is live.
  • The SourceTrac block is added and saved in Settings → Checkout → Customize → Thank you.
  • Test with a new order, because each order can be answered once.
  • The store is not on Shopify Starter.

Still stuck? The answers to common questions are on the SourceTrac FAQ.
